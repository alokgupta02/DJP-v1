# DJP PROTOTYPE QA & TESTS OPERATIONAL RULES

## Context Allocation
* Read `prototype/tests/test-todo.md`, `prototype/todo.md`, and `prototype/.djp_state.md` before executing tasks.
* Coordinate with `prototype/frontend/` (FE Agent) and `prototype/backend/` (BE Agent) so all domains stay aligned.

* Ensure test scripts (`api-health.test.mjs`, `auth.test.js`) verify happy path and key validation states.
* Record test execution outcomes and verification commands explicitly in `prototype/tests/.djp_state.md`.
