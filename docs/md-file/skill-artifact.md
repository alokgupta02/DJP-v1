| Icon | Command | Description |
| :-: | :--- | :--- |

| 🧹 | **`/ponytail-audit`** | Run a full-repository over-engineering audit. |
| 📒 | **`/ponytail-debt`** | Harvest deferred shortcuts (`ponytail:` comments) into a tracked ledger. |
| 📈 | **`/ponytail-gain`** | View measured-impact scoreboard showing token and time savings. |
| ❓ | **`/ponytail-help`** | Show quick reference card for Ponytail commands. |
| 🕸️ | **`/graphify`** | Build a navigable knowledge graph (`graphify-out/`) on a local folder or Git repo. |
| 🔎 | **`/graphify query "<q>"`** | Query the knowledge graph using BFS/DFS traversals. |
| 🛣️ | **`/graphify path "<A>" "<B>"`** | Find the shortest structural path between two nodes/concepts. |
| 📖 | **`/graphify explain "<c>"`** | Provide a plain-language explanation of a specific node or concept. |
| 🧩 | **`/chrome-extensions`** | Build and debug Chrome Extensions using Manifest V3 guidelines. |

## 💡 Best Practices for Using Skills

* **⚡ Slash Commands**: Type any command directly in your prompt to trigger specialized workflows immediately (e.g., `/ponytail lite` or `/tdd`).
* **🧠 Context Injection**: When triggered, the agent automatically loads the corresponding `SKILL.md` instructions into the active context window.
