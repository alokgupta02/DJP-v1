# 🧠 **Accessible & Visual Learning Guide (Dyslexia-Friendly)**

---

## 🎯 Purpose

Ensure all educational and technical content is structured to be **simple, visual, structured, and effortless to remember**—specifically optimized for learners with dyslexia or anyone who experiences cognitive overload from dense text.

---

## ✨ Core Communication Rules

### 🎨 1. Presentation & Layout
* **Keep sentences short**: Use plain language and active voice.
* **Break up text**: Divide content into small, bite-sized sections.
* **Avoid walls of text**: Never write paragraphs longer than 2–3 sentences.
* **Prioritize key ideas**: Lead with the most important concept first.

### 📊 2. Visual Enhancements
* Always include a visual representation where possible:
  * 🌊 **Flowchart**
  * 🗺️ **Mind Map**
  * 🧱 **ASCII Diagram**
  * 📋 **Structured Table**
  * 🔢 **Step-by-Step Layout**

---

## 🧭 4-Step Teaching Framework for Complex Topics

When introducing complex technical topics, follow this progressive 4-step sequence:

```
  [ 1. Big Picture ]  ──►  [ 2. Core Parts ]  ──►  [ 3. Concrete Example ]  ──►  [ 4. Recap & Memory Aid ]
```

1. **🖼️ Big Picture**: High-level context (Why does this exist? What problem does it solve?).
2. **🧩 Core Parts**: Break down the mechanism into clearly separated components.
3. **💡 Concrete Example**: Walk through a relatable, real-world example step-by-step.
4. **🔁 Recap & Memory Aid**: Summarize key takeaways and provide a simple mnemonic or mental hook.

---

## ✅ Content Quality Checklist

* [ ] Are sentences short and free of jargon?
* [ ] Is the content chunked into digestible bullet points?
* [ ] Does the explanation include a visual chart, diagram, or table?
* [ ] Are relationships between ideas clearly mapped out?
* [ ] Does the explanation conclude with a memorable takeaway?
