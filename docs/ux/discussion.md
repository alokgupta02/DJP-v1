# Discussion Documentation

**Purpose**: Standardized format for creating and managing conversation threads  
**Audience**: Developers, content creators, contributors  
**Status**: Stable  

---

## Overview

The Discussion Documentation outlines how to create and manage conversation threads within the Digital Janata platform.

## Content Structure

- **title**: Topic heading for the discussion
- **content**: Detailed conversation content
- **related_issue_id**: Reference to a related issue (if any)
- **author**: User who initiated the discussion
- **replies**: Array of comments/responses
- **tags**: Keywords for categorization
- **status**: Discussion status (Active, Archived)

## Usage Guidelines

- Use clear, concise language
- Use @mentions to reference other users
- Link to related discussions or polls when relevant
- Mark discussions as archived when no longer active
