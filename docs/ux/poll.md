# Poll Documentation

**Purpose**: Standardized format for creating and managing polls  
**Audience**: Developers, content creators, contributors  
**Status**: Stable  

---

## Overview

The Poll Documentation provides a standardized format for creating and managing polls within the Digital Janata platform.

## Content Structure

- **question**: Main question text
- **options**: Array of poll choices
- **option_votes**: Array of vote counts for each option
- **start_date**: Poll start timestamp
- **end_date**: Poll end timestamp
- **results_visibility**: Who can see results (participants only or public)
- **status**: Poll status (Active, Closed)

## Usage Guidelines

- Create clear, unbiased questions
- Provide mutually exclusive options
- Set appropriate time limits
- Configure result visibility based on audience
- Update poll status as needed
