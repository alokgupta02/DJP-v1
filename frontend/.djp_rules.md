# DJPv1 FRONTEND OPERATIONAL RULES

## Context Allocation
* Always refer to `frontend/todo.md` and `frontend/ARCHITECTURE.md` before editing UI code.
* Keep component depth under 3 levels unless domain complexity requires it.

## Code Quality Standards
* Prefer inline Tailwind utility classes over abstract CSS wrappers.
* Implement accessible HTML tags and handle error/loading UI states gracefully.
* Keep explanations dyslexia-friendly with clear bullet points.
